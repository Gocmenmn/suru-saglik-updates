# Sürü Sağlık güncellemeleri

Bu depo Sürü Sağlık Android uygulamasının imzalı kurulum paketlerini ve sürüm
bilgilerini yayımlamak için kullanılır. Uygulamanın kaynak kodu burada tutulmaz.

Kullanıcılar yalnız Android'in standart güncelleme onayını verir. Aynı paket adı
ve imzalama sertifikası korunduğu için mevcut hesap ve cihaz kayıtları silinmez.
